# 🎬 CineCut AI Studio Pro – Full Source Code & Engine

**منصة سينيكات الذكاء الاصطناعي الاحترافية لمعالجة واستخراج النصوص وعزل الصوت بالذكاء الاصطناعي.**

---

## 🚀 المميزات الرئيسية (Core Features):

1. **🎤 عزل الصوت البشري فائق النقاء (Zero-Bleed Audio Separation)**:
   - استخدام نموذج Meta Demucs 6-Stem المدعوم بكرت الشاشة CUDA لعزل صوت الفنان/المتحدث عن الموسيقى بدقة استوديو.

2. **🎙️ تفريغ واستخراج النص بالذكاء الاصطناعي (OpenAI Whisper)**:
   - تفريغ النصوص بدقة إملائية متناهية لدعم اللغة العربية الفصحى وجميع اللهجات السعودية والخليجية والمصرية والشامية.

3. **🎬 استوديو تصاميم الكلمات وتتر النهاية (Kinetic Subtitles & Credits Studio)**:
   - 4 أنماط سينمائية: شارة ختام الأفلام، كاريوكي بالكلمة، ترجمة سينمائية (CapCut)، ونص كلاسيكي فصيح.
   - مكتبة خطوط عربية عالمية: القاهرة (Cairo)، تجوال (Tajawal)، أميري (Amiri)، المراعي، الرقعة، والكوفي.
   - منقي ألوان مخصص بالكامل (Color Picker) + ألوان جاهزة.
   - محرر نص قابل للتعديل والتقسيم مع معاينة حية سريعة فوق مشغّل الفيديو.

4. **🔥 حرق النص والتتر على الفيديو نهائياً (FFmpeg ASS Subtitle Burner)**:
   - حرق النص المخصص مباشرة بداخل ملف الفيديو بصيغة MP4 وبأعلى جودة.

5. **⚡ ترقية الجودة وتنعيم الحركة (4K UHD 120 FPS Video Upscaler)**:
   - استخدام محرك NVENC CUDA Hardware لقفل الحركة وترقية مقاطع الفيديو بدقة 3840×2160.

---

## 🛠️ كيفية التشغيل محلياً (How to Run Locally):

1. **متطلبات النظام**:
   - Python 3.10 / 3.11 / 3.12
   - FFmpeg مثبت على النظام
   - PyTorch + CUDA (اختياري للسرعة القصوى عبر كرت الشاشة)

2. **تثبيت المكاتب**:
   ```bash
   pip install -r requirements.txt
   ```

3. **تشغيل السيرفر**:
   - اضغط مرتين على `Run_Studio_GPU.bat`
   - أو قم بتشغيل الأمر:
     ```bash
     python server.py
     ```
   - افتح المتصفح على: `http://127.0.0.1:5000`
